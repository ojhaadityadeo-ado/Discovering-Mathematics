MATH DETECTIVE: CASE FILE #6

Subject: Counting a Union

Mission: Understand and prove \(|A\cup B|=|A|+|B|-|A\cap B|\).

Detective Briefing: This case is about counting. The main question is simple: if we count the elements of \(A\) and the elements of \(B\), what happens to the elements that belong to both sets?

Before We Begin: What Does \(|A|\) Mean?

If \(A\) is a finite set, then \(|A|\) means the number of elements in \(A\). This number is called the cardinality of \(A\).

For example, if \(A=\{2,4,6\}\), then \(|A|=3\).

If \(S=\{a,b,c,d\}\), what is \(|S|\)?

🕵️ Detective's Note: Count how many elements are listed in the set.
Important
The bars in \(|A|\) do not mean absolute value here. They mean: how many elements are in the set?

Act 1: First Understand Why the Formula Should Be True

Suppose we want to count all elements in \(A\cup B\). A natural first thought is to add \(|A|\) and \(|B|\).

If \(A\) and \(B\) have no common elements, would \(|A|+|B|\) give the correct number of elements in \(A\cup B\)?

🕵️ Detective's Note: If the sets do not overlap, every element appears in only one of the two counts.
Now suppose the sets do overlap. If an element lies in \(A\cap B\), then it is counted once in \(|A|\) and once again in \(|B|\).

So how many times is each element of \(A\cap B\) counted in \(|A|+|B|\)?

🕵️ Detective's Note: An element in the intersection belongs to A and also to B.

But in \(A\cup B\), each element should be counted only:

🕵️ Detective's Note: A set does not list the same element twice.

What should we do to correct the double counting?

🕵️ Detective's Note: The common elements were counted one extra time, so remove one copy of them.
The whole idea
\[ |A|+|B| \] counts every element of the union, but it counts the elements in \(A\cap B\) twice. So we subtract the number of common elements once: \[ \boxed{|A\cup B|=|A|+|B|-|A\cap B|}. \]

Act 2: A Small Example

Let \[ A=\{1,2,3,4\},\qquad B=\{3,4,5\}. \] Then \[ |A|=4,\qquad |B|=3,\qquad A\cap B=\{3,4\},\qquad |A\cap B|=2. \] Also, \[ A\cup B=\{1,2,3,4,5\}, \] so \(|A\cup B|=5\).

If we simply add \(|A|+|B|\), what do we get?

🕵️ Detective's Note: Add 4 and 3.

Why is 7 too large?

🕵️ Detective's Note: Look at the two elements in the intersection.
Therefore, \[ |A\cup B|=4+3-2=5. \] The subtraction removes the extra counting of the common elements.

Act 3: Formal Proof

Now we prove the result carefully.

Split \(B\) into two parts:
  • the elements of \(B\) that are also in \(A\), namely \(A\cap B\);
  • the elements of \(B\) that are not in \(A\), namely \(B-A\).
These two parts do not overlap.

Therefore \(B\) is the disjoint union of \(A\cap B\) and \(B-A\). What does this give?

🕵️ Detective's Note: For disjoint finite sets, the number of elements in their union is the sum of their sizes.

So we can rearrange this as:

🕵️ Detective's Note: Move \(|A\cap B|\) to the other side.
Next observe that \[ A\cup B=A\cup(B-A). \] Why? The elements of \(B\) already inside \(A\) are already counted in \(A\). The only new elements that \(B\) contributes are the elements of \(B-A\).

Also, \(A\) and \(B-A\) are disjoint. Therefore:

🕵️ Detective's Note: Now we are adding two disjoint sets, so no element is counted twice.

Substitute \(|B-A|=|B|-|A\cap B|\). We get:

🕵️ Detective's Note: Replace \(|B-A|\) by the expression found just above.
Formal proof in one line
Since \(B=(A\cap B)\,\dot\cup\,(B-A)\), \[ |B-A|=|B|-|A\cap B|. \] Since \(A\cup B=A\,\dot\cup\,(B-A)\), \[ |A\cup B|=|A|+|B-A| =|A|+|B|-|A\cap B|. \] Hence \[ \boxed{|A\cup B|=|A|+|B|-|A\cap B|}. \]

Final Check: What Is the Subtraction Really Doing?

Which statement best explains the term \(-|A\cap B|\)?

🕵️ Detective's Note: The common elements should remain in the union; we only remove their extra count.
Notice
We are not saying that the elements of \(A\cap B\) are removed from \(A\cup B\). They remain in the union. We subtract \(|A\cap B|\) only because those elements were counted twice in \(|A|+|B|\).

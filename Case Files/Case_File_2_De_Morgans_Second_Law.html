MATH DETECTIVE: CASE FILE #2

Subject: De Morgan's Second Law

Mission: Prove \((A\cap B)'=A'\cup B'\) by following an arbitrary element through the definitions.

Detective Briefing: Complements are taken relative to a fixed universal set \(U\). We begin the proof immediately. Remember: to prove two sets are equal, we must eventually establish both subset directions.

Act 1: First Trail — Prove \((A\cap B)'\subseteq A'\cup B'\)

Start the proof: Let \(x\in(A\cap B)'\).

Before following the clues: what kind of element is \(x\)?

🕵️ Detective's Note: A subset proof must work for every element of the starting set, so we choose no special element.
Why arbitrary?
If we show this arbitrary \(x\) must lie in \(A'\cup B'\), then the same reasoning applies to every element of \((A\cap B)'\). That is exactly what \((A\cap B)'\subseteq A'\cup B'\) means.

Decode the complement. From \(x\in(A\cap B)'\), we know:

🕵️ Detective's Note: Membership in the complement means non-membership in the original set.

Now focus on \(x\notin A\cap B\). What would it mean for \(x\) to belong to \(A\cap B\)?

🕵️ Detective's Note: Intersection means an element satisfies both membership conditions.

So if \(x\) is not in the intersection, which conclusion is forced?

🕵️ Detective's Note: To fail being in both sets, at least one of the two membership conditions must fail. It is not necessary that both fail.
Logic fingerprint
\[ \neg(P\land Q)\iff (\neg P)\lor(\neg Q). \] Here \(P\) is “\(x\in A\)” and \(Q\) is “\(x\in B\)”.

Translate non-membership into complements:

\(x\notin A\Rightarrow x\in\) , while \(x\notin B\Rightarrow x\in\) .

🕵️ Detective's Note: The complement of \(A\) is \(A'\).
🕵️ Detective's Note: The complement of \(B\) is \(B'\).

We have therefore reached \(x\in A'\) or \(x\in B'\). Which set records “in at least one”?

🕵️ Detective's Note: Union means membership in at least one of the sets.

Thus \(x\in A'\cup B'\). Since \(x\) was arbitrary, \((A\cap B)'\subseteq A'\cup B'\).

Act 2: Reverse Trail — Prove \(A'\cup B'\subseteq(A\cap B)'\)

Begin the converse: Let \(x\in A'\cup B'\).

What does membership in the union tell us?

🕵️ Detective's Note: Union corresponds to “or.”

Decode the complements. The previous clue becomes:

🕵️ Detective's Note: \(x\in A'\) means \(x\notin A\), and similarly for \(B'\).

If at least one of “\(x\in A\)” and “\(x\in B\)” fails, can \(x\) lie in \(A\cap B\)?

🕵️ Detective's Note: To be in an intersection, both conditions must hold. If even one fails, intersection membership fails.

Finally, translate \(x\notin A\cap B\) back into complement notation:

🕵️ Detective's Note: Being outside \(A\cap B\) is exactly being inside its complement.

Hence \(A'\cup B'\subseteq(A\cap B)'\).

Act 3: The Crucial “OR” Mystery

A common mistake is to say:

“If \(x\notin A\cap B\), then \(x\notin A\) and \(x\notin B\).”

Is that statement always true?

🕵️ Detective's Note: Imagine \(x\in A\) but \(x\notin B\). Is \(x\) in \(A\cap B\)?

Suppose \(x\in A\) but \(x\notin B\). Then which statements are true?

🕵️ Detective's Note: This example exposes why the answer must involve “or,” not “and.”
Key distinction
First Law: outside a union means outside both sets.
Second Law: outside an intersection means outside at least one set.

Act 4: What If the Starting Set Is Empty?

In the first direction we said, “Let \(x\in(A\cap B)'\).” What if \((A\cap B)'=\varnothing\)? Can we literally choose such an \(x\)?

🕵️ Detective's Note: The empty set has no elements.

Does this cause the subset proof to fail?

🕵️ Detective's Note: To disprove \(X\subseteq Y\), you need an element in \(X\) that is not in \(Y\). Can \(\varnothing\) provide one?
Formal foundation
\[ X\subseteq Y \iff \forall x\,(x\in X\Rightarrow x\in Y). \] When \(X=\varnothing\), there is no counterexample, so the implication is true for every \(x\). This is called vacuous truth.

Final Report: Close the Case

We have proved both directions. Which conclusion now follows?

🕵️ Detective's Note: Two sets are equal exactly when each is contained in the other.

Therefore, \[ \boxed{(A\cap B)'=A'\cup B'}. \]

Proof skeleton
\[ x\in(A\cap B)'\Rightarrow x\notin A\cap B \Rightarrow (x\notin A\ \text{or}\ x\notin B) \Rightarrow (x\in A'\ \text{or}\ x\in B') \Rightarrow x\in A'\cup B'. \] Then run the same chain backwards for the converse.

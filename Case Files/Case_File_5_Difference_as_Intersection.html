MATH DETECTIVE: CASE FILE #5

Subject: Difference as Intersection

Mission: Prove \(A-B=A\cap B'\).

Detective Briefing: This case is about seeing that the two sides describe the same set in two different ways.

The Global View: What Do Both Sides Mean?

Left side: \(A-B\)
\(A-B\) is the set of elements that are in \(A\) but are not in \(B\).

Another way to say this is: start with all elements of \(A\), and remove any elements that are also in \(B\).
Right side: \(A\cap B'\)
\(A\cap B'\) contains the elements that are in both \(A\) and \(B'\).

Being in \(B'\) means being not in \(B\). So the right side contains all elements that are in \(A\) and not in \(B\).
Main idea
Both sides describe exactly the same kind of element: \[ x\in A \quad\text{and}\quad x\notin B. \] The proof below makes this precise.

Which sentence best describes both sides?

🕵️ Detective's Note: Difference keeps elements of A that do not belong to B.

Act 1: First Trail — Prove \(A-B\subseteq A\cap B'\)

Begin: Let \(x\in A-B\).

What does this tell us?

🕵️ Detective's Note: A−B means keep x in A, but exclude x from B.

Since \(x\notin B\), what can we say?

🕵️ Detective's Note: The complement B′ contains the elements not in B.

Now we know \(x\in A\) and \(x\in B'\). Therefore:

🕵️ Detective's Note: x belongs to both A and B′, so use intersection.

Therefore \(A-B\subseteq A\cap B'\).

Act 2: Reverse Trail — Prove \(A\cap B'\subseteq A-B\)

Begin: Let \(x\in A\cap B'\).

What two facts do we get?

🕵️ Detective's Note: Intersection means both conditions are true.

Since \(x\in B'\), what does that mean about \(B\)?

🕵️ Detective's Note: Membership in B′ means not being in B.

So \(x\in A\) and \(x\notin B\). This means:

🕵️ Detective's Note: A−B is exactly the part of A outside B.

Therefore \(A\cap B'\subseteq A-B\).

Act 3: Match the Descriptions

Read the left side
\(A-B\): all elements of \(A\), with the elements that are also in \(B\) removed.
Read the right side
\(A\cap B'\): elements that are in \(A\) and also in \(B'\), which means they are in \(A\) and not in \(B\).

Why do these descriptions match?

🕵️ Detective's Note: Compare the condition for a single element x on both sides.
Key idea
Set difference can be written using intersection and complement: \[ \boxed{A-B=A\cap B'}. \] The phrase “in A but not in B” becomes “in A and in B′.”

Final Report: Close the Case

We proved both subset directions. What follows?

🕵️ Detective's Note: Mutual inclusion gives equality of sets.

Therefore, \[\boxed{A-B=A\cap B'}.\]

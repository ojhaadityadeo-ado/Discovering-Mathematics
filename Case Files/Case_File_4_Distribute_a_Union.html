CASE FILE

MATH DETECTIVE: CASE FILE #4

Subject: Distribute a Union

Mission: Prove \(A\cup(B\cap C)=(A\cup B)\cap(A\cup C)\).

Detective Briefing: You already know how union, intersection, and membership work. In this case, focus on the main idea: how one union condition spreads across an intersection.

The Global View: What Is This Law Saying?

Think before proving
An element is in \(A\cup(B\cap C)\) if it is either in \(A\), or it is in both \(B\) and \(C\).

On the right side, the element must pass two checks: it must be in \(A\cup B\), and it must also be in \(A\cup C\).

If the element is already in \(A\), it passes both checks. If it is not in \(A\), then it must be in both \(B\) and \(C\).

Which sentence gives the best overall picture?

🕵️ Detective's Note: Read the left side aloud: “in A OR (in B AND in C).”
Logic fingerprint
If \(P:x\in A\), \(Q:x\in B\), and \(R:x\in C\), then the pattern is \[ P\lor(Q\land R)\iff (P\lor Q)\land(P\lor R). \]
Remark: If you do not know this logical notation, you can simply ignore it and continue with the set proof.

Act 1: First Trail — Prove \(A\cup(B\cap C)\subseteq(A\cup B)\cap(A\cup C)\)

Begin: Let \(x\in A\cup(B\cap C)\).

What does this tell us?

🕵️ Detective's Note: The outer operation is a union.

So there are two cases. Suppose first that \(x\in A\). What can we say?

🕵️ Detective's Note: If x is in A, it automatically belongs to any union containing A.

Now suppose instead that \(x\in B\cap C\). Then \(x\in B\) and \(x\in C\). What follows?

🕵️ Detective's Note: Membership in B puts x in A∪B, and membership in C puts x in A∪C.

In both cases we have the same conclusion:

🕵️ Detective's Note: We know x is in both sets on the right, so use intersection.

Therefore \(A\cup(B\cap C)\subseteq(A\cup B)\cap(A\cup C)\).

Act 2: Reverse Trail — Prove \((A\cup B)\cap(A\cup C)\subseteq A\cup(B\cap C)\)

Begin: Let \(x\in(A\cup B)\cap(A\cup C)\).

Then which two facts are true?

🕵️ Detective's Note: The outer operation is an intersection, so both conditions hold.
The useful split
Ask one simple question: Is \(x\in A\)?

If yes, we are already done because \(x\in A\cup(B\cap C)\).
If no, then the two unions force something else to happen.

Suppose \(x\notin A\). Since \(x\in A\cup B\), what must be true?

🕵️ Detective's Note: A union says at least one membership is true. If A is ruled out, B must be true.

Also, since \(x\in A\cup C\) and \(x\notin A\), what must be true?

🕵️ Detective's Note: Use the same reasoning with A∪C.

Therefore, if \(x\notin A\), then:

🕵️ Detective's Note: We have x∈B and x∈C.

So whether \(x\in A\) or \(x\notin A\), what can we conclude?

🕵️ Detective's Note: Either x is in A, or it is in B∩C.

Hence \((A\cup B)\cap(A\cup C)\subseteq A\cup(B\cap C)\).

Act 3: What Was Distributed?

Which matching is correct?

🕵️ Detective's Note: A union needs at least one condition; an intersection needs both.

Why does \(A\) appear in both unions on the right?

🕵️ Detective's Note: If x∈A, then x∈A∪B and x∈A∪C automatically.
Proof idea
\[ x\in A\cup(B\cap C) \Rightarrow x\in A\ \text{or}\ (x\in B\ \text{and}\ x\in C). \] This gives \[ x\in A\cup B\quad\text{and}\quad x\in A\cup C. \] So \(x\in(A\cup B)\cap(A\cup C)\).

Act 4: Is This True?

Claim under investigation
Is \[ A\cup(B\cap C)=(A\cup B)\cap C \] true for all sets?
Counterexample
Take \[ A=\{1\},\qquad B=\{2\},\qquad C=\{2\}. \] Then \[ B\cap C=\{2\}, \] so \[ A\cup(B\cap C)=\{1,2\}. \] But \[ A\cup B=\{1,2\}, \] and therefore \[ (A\cup B)\cap C=\{2\}. \] Hence \[ A\cup(B\cap C)\neq(A\cup B)\cap C. \] So this statement is not true in general.
Why does it fail?
On the left, every element of \(A\) is included.
On the right, an element of \(A\) is kept only if it is also in \(C\).

The correct distribution is \[ (A\cup B)\cap\boxed{(A\cup C)}, \] not \((A\cup B)\cap C\).

What does this remind us about union and intersection?

🕵️ Detective's Note: Mixed operations need the correct distributive rule.

Final Report: Close the Case

We proved both subset directions. What follows?

🕵️ Detective's Note: Mutual inclusion gives equality of sets.

Therefore, \[ \boxed{A\cup(B\cap C)=(A\cup B)\cap(A\cup C)}. \]

Key idea
When A is unioned with an intersection, A appears in both unions on the right.

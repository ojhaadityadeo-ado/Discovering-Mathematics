Subject: De Morgan's First Law

Mission: Prove \((A\cup B)'=A'\cap B'\) by understanding exactly what equality, subset, complement, union, and intersection mean.

Detective Briefing: Assume all complements are taken relative to a fixed universal set \(U\). Your job is not to memorize De Morgan's Law. Your job is to reconstruct why it must be true, one logical clue at a time.

Act 4: The Empty-Set Mystery

At the beginning of a subset proof, we often say: “Let \(x\in X\).” But what if \(X=\varnothing\)? Can we actually pick such an element?

🕵️ Detective's Note: The defining feature of \(\varnothing\) is that it contains no elements.

Then why is \(\varnothing\subseteq Y\) true for every set \(Y\)?

🕵️ Detective's Note: To disprove \(X\subseteq Y\), you need a counterexample: an element in X but not Y. Can the empty set supply one?
Foundation Check
The formal subset statement is \[ X\subseteq Y \quad\Longleftrightarrow\quad \forall x\,(x\in X\Rightarrow x\in Y). \] If \(X=\varnothing\), the implication has no counterexample, so the statement is true. This is called vacuous truth.

Proof Skeleton to Remember
To prove two sets \(X\) and \(Y\) are equal: prove \(X\subseteq Y\), then prove \(Y\subseteq X\). In each direction, start with an arbitrary element of the first set and use definitions until you show it lies in the second.

MATH DETECTIVE: CASE FILE #3

Subject: Distribute an Intersection

Mission: Prove \(A\cap(B\cup C)=(A\cap B)\cup(A\cap C)\), and identify exactly why the distribution works.

Detective Briefing: By now, union, intersection, membership, and the two-subset method should be familiar. This case moves faster. Your job is to recognize the logical structure hidden inside the set notation.

The Global View: What Is This Law Really Saying?

Think of A as a filter
Start with everything that lies in either \(B\) or \(C\). Now keep only the elements that also lie in \(A\).

There are only two ways an element can survive that filter: it is in \(A\) and \(B\), or it is in \(A\) and \(C\).

Which sentence best captures the law before we prove it?

🕵️ Detective's Note: Read \(A\cap(B\cup C)\) aloud: “in A AND (in B OR in C).”
Logic fingerprint
If \[ P: x\in A,\qquad Q:x\in B,\qquad R:x\in C, \] then the set identity is powered by \[ P\land(Q\lor R)\iff (P\land Q)\lor(P\land R). \] This is the logic behind the proof.

Remark: If you do not know this logical notation yet, you can simply ignore this box and continue with the set proof.

Act 1: First Trail — Prove \(A\cap(B\cup C)\subseteq(A\cap B)\cup(A\cap C)\)

Begin: Let \(x\in A\cap(B\cup C)\).

We do not need to re-learn the definition of intersection. Decode the statement in one move:

🕵️ Detective's Note: The outer operation is an intersection.

The second part, \(x\in B\cup C\), gives us two possible cases. Which logical statement now describes everything we know?

🕵️ Detective's Note: Do not lose the parentheses. The fact “\(x\in A\)” must remain true in either branch.

Now distribute the logical “and.” What follows?

🕵️ Detective's Note: The condition \(x\in A\) belongs to both branches. Distribution does not allow it to disappear from the second branch.
The decisive step
\[ x\in A\ \land\ (x\in B\lor x\in C) \Rightarrow (x\in A\land x\in B)\lor(x\in A\land x\in C). \] This is the conceptual heart of the proof.

Translate each branch back into set notation:

🕵️ Detective's Note: Each “and” becomes an intersection.

And “one branch or the other” means:

🕵️ Detective's Note: “Or” translates to union.

Therefore \(A\cap(B\cup C)\subseteq(A\cap B)\cup(A\cap C)\).

Act 2: Reverse Trail — Prove \((A\cap B)\cup(A\cap C)\subseteq A\cap(B\cup C)\)

Begin the converse: Let \(x\in(A\cap B)\cup(A\cap C)\).

This means one of two branches is true. What is the correct unpacking?

🕵️ Detective's Note: First decode the outer union; then decode the two intersections.

What crucial fact is true in both branches?

🕵️ Detective's Note: Compare the two branches and look for the repeated condition.

What else can we conclude, regardless of which branch occurred?

🕵️ Detective's Note: The first branch supplies B; the second supplies C. Either way, membership in the union follows.

So we now have \(x\in A\) and \(x\in B\cup C\). Therefore:

🕵️ Detective's Note: Two facts connected by “and” become an intersection.

Hence \((A\cap B)\cup(A\cap C)\subseteq A\cap(B\cup C)\).

Act 3: What Exactly Was Distributed?

The notation can make the proof look algebraic, but the real mechanism is logical. Which operation plays the role of “and,” and which plays the role of “or”?

🕵️ Detective's Note: To belong to an intersection you must satisfy both conditions; to belong to a union at least one condition is enough.

Which statement best explains why the factor \(A\) appears twice on the right-hand side?

🕵️ Detective's Note: In \(A\cap(B\cup C)\), A is not tied only to B; it is a requirement for the whole parenthesized union.
Proof skeleton
\[ \begin{aligned} x\in A\cap(B\cup C) &\Rightarrow x\in A\ \text{and}\ (x\in B\ \text{or}\ x\in C)\\ &\Rightarrow (x\in A\ \text{and}\ x\in B)\ \text{or}\ (x\in A\ \text{and}\ x\in C)\\ &\Rightarrow x\in(A\cap B)\cup(A\cap C). \end{aligned} \] The converse reverses the same logical structure.

Act 4: Is This True?

Claim under investigation
Someone writes \[ A\cap(B\cup C)=(A\cap B)\cup C. \] Is this true for all sets?

What should we notice before checking an example?

🕵️ Detective's Note: Look at an element of C. On the left, must it also be in A?
Counterexample
Take \[ A=\{1\},\qquad B=\{1\},\qquad C=\{2\}. \] Then \[ B\cup C=\{1,2\}, \] so \[ A\cap(B\cup C)=\{1\}. \] But \[ A\cap B=\{1\}, \] so \[ (A\cap B)\cup C=\{1,2\}. \] Therefore \[ A\cap(B\cup C)\neq(A\cap B)\cup C. \] So the statement is not true in general.
Why does it fail?
On the left, an element from \(C\) must also be in \(A\). On the right, every element of \(C\) is included automatically.

So the correct distribution is \[ (A\cap B)\cup\boxed{(A\cap C)}, \] not merely \((A\cap B)\cup C\).

What does this tell us about union and intersection?

🕵️ Detective's Note: Brackets can be moved freely for repeated unions or repeated intersections. When union and intersection are mixed, we need the correct distributive law.

Final Report: Close the Case

We proved both subset directions. What may we conclude?

🕵️ Detective's Note: Mutual inclusion is the criterion for equality of sets.

Therefore, \[ \boxed{A\cap(B\cup C)=(A\cap B)\cup(A\cap C)}. \]

Key idea
“A must survive in every branch.”
When \(A\) is intersected with a union, the condition “be in \(A\)” must appear in both parts.
